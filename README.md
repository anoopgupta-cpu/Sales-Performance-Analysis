# Sales-Performance-Analysis
Sales data analysis and Power BI dashboard project
Project Overview

This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI with sales data imported from Microsoft Excel.

The objective is to provide a visual overview of sales performance through key performance indicators (KPIs), charts, and business insights.

🎯 Business Objectives

- Monitor overall sales performance.
- Analyze total revenue and order volume.
- Understand customer and product performance.
- Explore geographical sales distribution.
- Identify key sales trends and patterns.

🛠️ Tools Used

- Microsoft Excel
- Microsoft Power BI

📈 Key Performance Indicators

- Total Revenue
- Total Orders
- Unique Customers
- Average Order Value

🔍 Dashboard Components

1. Revenue and order performance KPIs.
2. Quantity vs Revenue Analysis.
3. Geographical Sales Performance.
4. Product-wise Revenue Analysis.
5. Country-wise Revenue Analysis.
6. Key Business Insights.
